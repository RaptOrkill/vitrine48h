# Vitrine48h

Sites vitrines professionnels pour artisans et indépendants — 249 €, livrés en 48 h, payés à la livraison.

## Structure

- `index.html` — landing de vente
- `demo-plomberie/` — démo plombier (Plomberie Bastin & Fils, Lyon — fictif)
- `demo-institut/` — démo institut de beauté (L'Écrin de Jade, Bordeaux — fictif)
- `demo-electricien/` — démo électricien (Voltéo, Nantes — fictif)
- `GUIDE-LANCEMENT.md` — textes de prospection prêts à l'emploi (Leboncoin, Facebook, Meta Ads, script de closing)

## Avant de prospecter (2 min)

1. Dans `index.html`, en bas du fichier : remplacer `PHONE_WHATSAPP` et `PHONE_DISPLAY` par ton vrai numéro.
2. Dans le pied de page de `index.html` : compléter nom, SIRET, adresse.
3. Commit + push → le site se met à jour automatiquement (GitHub Pages).

Toutes les entreprises des démos sont fictives (numéros dans les tranches réservées à la fiction, adresses inventées) et marquées comme telles en pied de page.
